### The Breath reconciliation (ED-003)

Proposal `proposals/breath-19.yaml` encodes the approved sequence: 14 existing selections are kept in the
new order, Fleisher's BWV 208 transcription is retired, and five new selections are added. Four of the new
ones still need song IDs. BWV 127/III has an editor-supplied URL that still needs confirming. Applying it
gives Breath 19 selections and the playlist 673.

```sh
uv run atlas proposal check breath-19
```

When it is applied, Fleisher's close-listening study ("Compare the piano transcription with the sung pastoral
aria…") is kept with the retired record. Whether it should move to the Hewitt/Mary Howe selection is an
editorial decision.

### Itinerary wording (ED-011)

## Resolving an issue

1. Make the data change (see [CONTRIBUTING.md](../CONTRIBUTING.md)).
2. Set the issue's `status` to `resolved` (or `wont_fix`) and explain the decision in `detail`.
3. `uv run atlas validate && uv run atlas audit && uv run pytest`, then commit data and reports together.
