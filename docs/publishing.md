# Publishing the website (GitHub Pages)

The site is plain static files generated by `uv run atlas build` into `_site/`. There is no server
component.

## One-time setup (after the GitHub repository exists)

1. Push the repository to GitHub.
2. In **Settings → Pages**, set **Source** to **GitHub Actions**.
3. Push to `main` (or run the **Pages** workflow manually from the Actions tab).

`.github/workflows/pages.yml` validates the data, builds the site with the correct base path (taken from
`actions/configure-pages`), and deploys it. The site will be at
`https://<owner>.github.io/the-listening-atlas/` (or your custom domain).

## Local preview

```sh
uv run atlas build && uv run atlas serve     # http://127.0.0.1:8000/
```

## Notes

- All internal links are relative, so the same build works at a domain root or under `/the-listening-atlas/`.
  Only `404.html` uses absolute links (GitHub Pages serves it at any path); the workflow passes `--base-url`
  for it.
- `.nojekyll` is emitted so GitHub serves files as-is.
- To use a custom domain, add it in Settings → Pages. No code change is needed.
